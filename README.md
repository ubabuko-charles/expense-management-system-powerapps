# Expense Management System

## Overview

This is an Expense Management System built using Microsoft Power Apps, Power Automate, and SharePoint.

It enables employees to submit expense requests while managers review and approve them through an automated workflow.

## Technologies Used

- Microsoft Power Apps
- Microsoft Power Automate
- Microsoft SharePoint

## Features

- Submit expenses
- Edit and delete expenses
- Approval workflow
- Email notifications
- Track expense status

Challenges Faced
One challenge was ensuring that employees could easily submit expense requests while managers could review and approve them efficiently. Another challenge was integrating Power Apps with SharePoint and Power Automate so that submitted expenses were stored correctly and approval emails were triggered automatically. I resolved these challenges by carefully designing the SharePoint list structure, testing the Power Automate workflow multiple times, and validating each stage before deployment.
________________________________________
Lessons Learned
Through this project, I gained hands-on experience in developing business applications with Microsoft Power Apps. I learned how to integrate Power Apps with SharePoint, automate approval workflows using Power Automate, manage data efficiently, and troubleshoot workflow issues. I also learned the importance of testing every component to ensure a smooth user experience.

Future Improvements
If I continue developing this project, I would:
•	Add role-based access so managers and employees have different permissions. 
•	Allow users to upload receipts with expense requests. 
•	Integrate Power BI dashboards for expense reporting. 
•	Replace SharePoint with Dataverse for improved scalability. 
•	Add mobile-friendly enhancements.
