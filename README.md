# Expense Management System

## Overview

This project is an Expense Management System built using Microsoft Power Apps, Power Automate, and SharePoint.

It allows employees to submit expense requests while managers can approve or reject them through an automated workflow.

## Features

- Submit expense requests
- Edit and delete requests
- Manager approval workflow
- Email notifications
- Track request status

## Technologies Used

- Microsoft Power Apps
- Microsoft Power Automate
- Microsoft SharePoint
